# mark-house-style

This repository holds Mark's own set-up for coding agents, and is read in
every repository through links from the home folder. See `README.md`.

- **This repository takes direct commits to `main`.** No branches or pull
  requests. The general rule still holds: never commit or push unless asked.
- **A change here applies everywhere at once**, because every repository
  reads these files through links. Say so when a change would alter how
  another repository behaves.
